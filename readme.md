# Чат с GigaChat

Консольный Python-клиент для работы c GigaChat через API. Выводит ответы, время выполнения и расход токенов. Сохраняет лог в `chat.log`.

## Установка

Работа клиента тестировалась на Python 3.12.

В папке проекта создайте виртуальное окружение и установите зависимости.

Windows PowerShell:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

## Настройки

Значения переменных находятся в файле `.env`:


| Параметр               | Назначение                                    |
| ---------------------- | --------------------------------------------- |
| `GIGACHAT_AUTH_KEY`    | Ключ авторизации GigaChat                     |
| `GIGACHAT_SCOPE`       | Область доступа, например `GIGACHAT_API_PERS` |
| `GIGACHAT_MODEL`       | Выбранная модель                              |
| `GIGACHAT_TEMPERATURE` | Температура генерации                         |


Переименуйте файл env в .env, замените значение `GIGACHAT_AUTH_KEY` в файле `.env` своим ключом. Для получения ключа:

- При необходимости, зарегистрируйтесь в Sber Studio.
[https://developers.sber.ru/docs/ru/gigachat/individuals-quickstart](https://developers.sber.ru/docs/ru/gigachat/individuals-quickstart)
- Войдите в Sber Studio.
- создайте проект «GigaChat API» → «Настройки API» → «Получить ключ».
- Скопируйте Authorization Key — он показывается только один раз.
**Не публикуйте ключ авторизации.**

При необходимости откорректируйте `prompt.txt` (кодировка UTF-8). Пример системного промпта:

```text
Ты — организатор досуга. Предложи 3 варианта, как провести вечер, учитывая интересы пользователя. Отвечай на русском.
```

После изменения настроек или промпта перезапустите программу.

## Запуск

```powershell
python main.py
```

Введите описание интересов пользователя и нажмите Enter. Для выхода введите `0`.

Каждое описание отправляется независимо: история предыдущих сообщений модели не передаётся. RAG и поиск по документам не используются.

## Логирование

Файл `chat.log` создаётся рядом с программой и дополняется при каждом запуске. В него записываются:

- Дата и время запуска.
- Системный промпт.
- Описания пользователей и ответы.
- Модель и температура генерации.
- Время выполнения запроса.
- Причина завершения генерации.
- Расход токенов.
